# Ερωτηματολόγιο Εξωτερικών API Consumers — προς Υπεύθυνο INCIS

Σκοπός: επιβεβαίωση/αποκλεισμός εξωτερικών εφαρμογών-αυτοματισμών που χρησιμοποιούν τα **API write endpoints** (`/api/v1/*`), πριν ενεργοποιηθεί το H-2 enforce.

## Αποδέκτης
Υπεύθυνος συστήματος / IT owner του INCIS SaaP.

## Ερωτήσεις (απάντηση: Ναι / Όχι / Άγνωστο + στοιχεία)
1. Υπάρχουν **εξωτερικές εφαρμογές** (mobile, desktop, 3rd-party) που καλούν `/api/v1/*`;
2. Υπάρχουν **integrations/scripts/RPA/ETL** που κάνουν **POST/PUT/DELETE** στο `/api/v1/clients|suppliers|incis|rawmaterials|restrictions|formulas`;
3. Χρησιμοποιείται **Bearer/JWT** ή **cookie session** για τις παραπάνω κλήσεις; (σημ.: το `Bearer` δεν είναι λειτουργικό — μόνο demo token)
4. Υπάρχει **API gateway / reverse proxy / WAF** μπροστά στο INCIS; (καταγραφές κλήσεων;)
5. Υπάρχουν **χρονοπρογραμματισμένες εργασίες** (Windows Task Scheduler, cron, Power Automate, Azure Functions) που γράφουν μέσω API;
6. Υπάρχουν **webhooks subscribers** (εξερχόμενες προς τρίτους) ή συνδρομές γεγονότων;
7. Υπάρχει **documented/contracted** API χρήση (συμβάσεις, SLA, ονόματα integrations, υπεύθυνοι);
8. Ποιοι **ρόλοι χρηστών** χρησιμοποιούνται για API κλήσεις; (σημ.: προβλεπόμενη πολιτική = Admin/SuperUser)
9. Υπάρχουν **εξωτερικοί προορισμοί SMTP** πέραν του ρυθμισμένου; (αν ναι, ποιοι)
10. Οτιδήποτε άλλο εκτός INCIS που αλληλεπιδρά (αρχεία, βάσεις, μηνύματα);

## Απαιτούμενο αποδεικτικό επιστροφής
- Κατάλογος integrations με: όνομα, ιδιοκτήτη, σκοπό, endpoints, ρόλο/διαπιστευτήριο, συχνότητα.
- Τυχόν **δείγματα logs** (χωρίς tokens/passwords) από gateway/proxy.
- Ρητή δήλωση: «**Δεν υπάρχουν** εξωτερικοί consumers» **ή** λίστα αυτών.

> **Σημείωση:** Η απουσία καταγραφών/logs **δεν** αποδεικνύει απουσία consumers. Η τελική επιβεβαίωση απαιτείται από τον υπεύθυνο.
