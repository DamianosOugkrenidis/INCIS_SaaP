# Μήνυμα προς PO (έτοιμο προς αποστολή)

**Θέμα:** INCIS SaaP — Απαιτείται γραπτή επιβεβαίωση εξωτερικών API consumers (μπλοκάρει το H-2/CSRF hardening)

Αγαπητέ/ή [Όνομα],

Για την ασφαλή ενεργοποίηση των νέων ελέγχων στα API write endpoints (`/api/v1/*`), χρειαζόμαστε **γραπτή επιβεβαίωση** για τυχόν εξωτερικά συστήματα που τα χρησιμοποιούν.

**Τι έχουμε επιβεβαιώσει από τον κώδικα (όχι από το περιβάλλον):**
- Δεν εντοπίστηκε consumer εντός του repository.
- Outbound: μόνο SMTP email και webhooks προς URL που ορίζει ο χρήστης.
- Τα API αυθεντικοποιούνται με **cookie** (Identity)· bearer/JWT δεν είναι ενεργό.

**Τι χρειαζόμαστε (ένα από τα δύο):**
1. **Λίστα** εξωτερικών consumers: όνομα, ιδιοκτήτης, endpoints (POST/PUT/DELETE), auth (cookie/token), συχνότητα· ή
2. **Ρητή δήλωση** ότι **δεν υπάρχουν**, με αναφορά στο εύρος που ελέγχθηκε.

**Προθεσμία (προτεινόμενη):** έως **[D+2 εργάσιμες]** — προς επιβεβαίωση.
**Αποδεικτικό:** συμπληρωμένο και υπογεγραμμένο το `docs/requests/PO_API_CONSUMERS_DECLARATION.md` (ερωτηματολόγιο: `PO_REQUEST.md`).

**Συνέπεια:** Χωρίς την παραπάνω επιβεβαίωση, τα `Api:WritePolicy:Enforce` και `Api:Csrf:Enforce` **παραμένουν απενεργοποιημένα** στην παραγωγή (Phase 0, log-only). Η απουσία καταγεγραμμένων κλήσεων **δεν** αποδεικνύει απουσία consumers.

Ευχαριστώ,
