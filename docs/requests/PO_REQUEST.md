## Σκοπός
Πριν ενεργοποιηθεί `Api:WritePolicy:Enforce` / `Api:Csrf:Enforce` στην παραγωγή, χρειαζόμαστε επιβεβαίωση για τυχόν εξωτερικά συστήματα που καλούν τα API write endpoints.

## Τι έχουμε ήδη εξακριβώσει από τον κώδικα (όχι από το περιβάλλον)
- **Δεν** εντοπίστηκε κανένας in-repo consumer των `/api/v1/*` writes.
- Outbound: μόνο SMTP email + webhooks προς URL που ορίζει ο χρήστης.
- Auth API: **cookie** (Identity)· bearer/JWT **δεν** είναι ενεργό.
- Άρα: **δεν μπορούμε να αποκλείσουμε** εξωτερικούς consumers → απαιτείται η δική σας επιβεβαίωση.
